# Contributing

Thanks for your interest in contributing to this project! I mostly created this project for my own use, but I'm happy to
accept contributions.

Especially from new developers that want to contribute.

For a detailed guide on how to set up an optional local development environment, see [Development Setup](DEVELOPMENT_SETUP.md).

## First-time contributors

Open an issue and just tell me about your idea. I'll try to help you get started.

Some ideas:

- Update some documentation or javadocs
- Write some tests
- Update the `examples` project

If you are interested in creating new utility methods, please open an issue first to discuss it.

## Pull Requests

There will always be a release branch with the current version to be released. For the current release train.
If there is code that has been changed inside the `lib` module.

If there is code/docs changed outside the `lib` module a pull request to the main branch is preferred.

## Code of Conduct

Be nice.

Thank you! :heart:
